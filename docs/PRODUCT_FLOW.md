# Web App 完整使用流程与部署边界

本文件说明当前源码已经实现的使用路径，不代表所有平台、账号和手机环境均已实测成功。

## 1. 首页

首页背景为静音循环视频；浏览器拦截播放时使用动态图降级。两个入口：

- **冰箱里有啥？**：输入手头食材，寻找已收录食谱。
- **给菜谱库加餐**：提交新的食谱来源，在后台识别并决定是否收录。

页面保留透明蓝金按钮和统一人物场景。视频、备用动画和界面图片均在 assets 中。

## 2. 用现有食材找菜谱

首页 → 冰箱食材页 → 输入/修改食材标签 → 选择菜系或不限菜系 → 查看匹配结果 → 打开料理便签。

匹配对象是已收录且未报错/归档的菜谱库，不是无限联网搜索或凭空生成新菜谱。拍照入口目前用于图片预览，不能把它宣传为已经实现的自动食材识别；仍需手动确认食材。

## 3. 连接小厨房

打开固定的 Cloudflare 网页地址 → 页面读取 /api/backend-address → 自动填入 D 盘后台通道地址 → 首次输入私人访问口令 → 验证成功后保存于当前浏览器。

返回前台及页面可见期间定时检查地址变化；地址变更后重新连接。清除网站数据、无痕模式、换浏览器或设备会需要重新输入口令。高级地址输入保留以便排查问题。可主动选择忘记口令。

电脑需保持后台和公网通道运行。公网网页能打开，不代表本机后台在线。登记地址一致也不代表该地址可连通。

## 4. 导入食谱

支持三种入口：

1. 提交平台分享链接，获取视频或图文；视频帖子正文与字幕、语音一起形成依据。
2. 上传 MP4/MOV 视频。上传完成前需保持页面打开；单个视频上限250MB、时长5分钟。
3. 链接失败时展开手动图文输入，粘贴正文并按顺序选择图片（最多12张，总20MB，单张8MB）。

纯画面中没有字幕、语音、正文说明的动作不等于已完成视觉理解；关键依据缺失时必须说明，不能补造。

## 5. 后台任务

提交后可继续添加其他识别任务或离开页面。后台持久队列最多10个待处理/运行任务，两个工作线程推进。下载浏览器、识别模型和绘图使用受控共享资源，两个任务不保证所有阶段同时跑。

每张任务卡显示名称/编号、当前阶段、耗时、失败原因、复核疑问和已恢复历史。阶段包括：获取内容 → OCR/语音/正文 → DeepSeek整理 → 复核和修正 → 插图 → 排版。

失败后保留原始依据和有效断点。“从断点继续”复用输入及规则一致的已完成阶段；改变来源或规则可能使相关阶段重新运行，模型调用仍可能收费。额度不足、登录失败、正文缺失不能通过无限重试解决。

## 6. 查看便签并作决定

结果不会自动收录。用户从任务卡点击“查看结果 · 收录或报错”，可查看食材与步骤、完整便签，填写菜名并选择菜系。

- **收录**：加入食谱库，之后可按食材/菜系查找。
- **不符合要求 · 报错**：填写漏步骤、用量错误、插图不对应等原因，后台保留反馈，便签不进入已收录列表。

有疑问的文字或未完成插图可查看；用户可选择收录，但问题标记不能被当作已解决。未收录结果从食谱库隐藏，后台仍保留；未收录不是识别错误。

## 7. 便签视觉契约

- 食材配独立插图、名称和原文明确的用量；无用量不虚构。
- 插图由绘图流程新生成并导入；自检不通过时不冒充正确图片。
- 食材与步骤之间有简约分界线。
- 步骤完整展开，简明文字注释加弧形箭头表示顺序，不要求逐步点开。
- 不提供逐步“我已做完”的确认，也不使用烹饪时间进度条。
- 食谱列表卡片不需要每张附插图；真正的食材与步骤插图在便签中。

## 8. 报错库

分别记录用户报错、自动复核问题、插图问题和长期未收录归档。系统保留证据以便维护者分析；不会把模型建议直接变成规则，不提供自动修复所有错误的保证。外部 Codex 会话中的定期审查任务不随 GitHub 仓库迁移，需由所有者另外配置。

## 9. 哪些部署到哪里

| 位置 | 文件/内容 | 作用 |
| --- | --- | --- |
| Cloudflare 静态资源 | build_cloudflare.py 生成的 cloudflare-pages/ | 手机网页、样式、脚本、媒体、PWA |
| Cloudflare Worker | address_worker.mjs | 提供地址登记 API，并转发静态页面 |
| Cloudflare KV | ADDRESS_BOOK | 仅存后台最新地址与更新时间 |
| Cloudflare Secret | ADDRESS_WRITE_TOKEN | 限制谁可以更新地址 |
| 自己的电脑或服务器 | cloud_server.py、识别/复核/绘图模块 | 实际处理任务 |
| 私有 work 目录 | 数据库、密钥、登录状态、原始视频和结果 | 不上传到 GitHub 或公开静态站点 |

源码包包含所有前述部署代码、素材、示例配置和构建命令；不包含你账户中已经部署的 KV 数据、Secret、域名配置和私人内容。部署到新账户时必须填写自己的配置，不能直接沿用他人的地址或凭据。
